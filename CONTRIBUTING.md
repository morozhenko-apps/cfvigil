# Feedback and contributions

CFVigil is independently developed and maintained. Bug reports and practical suggestions are welcome, but the upstream repository does not accept outside pull requests or patches.

If you encounter a problem, open a [bug report](https://github.com/morozhenko-apps/cfvigil/issues/new?template=bug_report.yml). Tell me what you did, what you expected, what happened instead and which operating system you use. Before attaching screenshots or logs, remove API tokens, private project identifiers and personal information.

If there's something that would make CFVigil more useful, use the [improvement suggestion form](https://github.com/morozhenko-apps/cfvigil/issues/new?template=feature_request.yml). Describing the situation matters more than proposing code. Suggestions are considered individually and aren't a promise that a particular feature will be added.

Please report security vulnerabilities through [private GitHub Security Advisories](https://github.com/morozhenko-apps/cfvigil/security/advisories), not public Issues.

The [Apache License 2.0](LICENSE) permits independent forks and modifications subject to its terms and [NOTICE](NOTICE) obligations. An unofficial fork should not be represented as an official CFVigil release.
