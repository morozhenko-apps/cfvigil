# Localization review checklist

Review each supported language in the actual desktop interface, not only as individual strings. Use the catalogs under the UI source directory as the current language inventory.

Check deployment/build wording, status meaning, Cloudflare terminology, plural forms, elapsed time, date formatting, error messages, Settings, Event History, native tray menus, keyboard descriptions and accessibility labels. Confirm that resource identifiers and API permission names retain their original technical meaning.

Review narrow cards, expanded lists, long resource names, CJK font rendering, Indic and Thai scripts, and Arabic right-to-left layout. Ensure controls remain usable at desktop scaling and translated messages cannot be confused with a confirmed deployment success.

Track specific editorial defects and their verified resolution in issues and test reports. Do not append per-language draft diaries, private machine observations or dated acceptance narratives to this file.
